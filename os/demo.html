🧪 AdrianLAB OpenSea Integration

🚀 Características Principales

  • Resumen completo de la colección AdrianLAB
  • Explorador de NFTs con búsqueda y filtrado
  • Marketplace con listings y ofertas en tiempo real
  • Historial de eventos y transacciones
  • Analytics con gráficos de precios
  • Diseño responsive para todos los dispositivos
  • Integración completa con OpenSea API v2

📱 Cómo Usar

  1. Resumen: Ve estadísticas generales de la colección
  2. NFTs: Explora todos los NFTs con búsqueda y filtros
  3. Marketplace: Ve listings activos y ofertas
  4. Eventos: Revisa el historial de transacciones
  5. Analytics: Analiza métricas y gráficos de precios

🛠️ Endpoints de API Utilizados

GET /chain/ethereum/contract/{address} # Info de colección GET /collections/{address}/stats # Estadísticas GET /chain/ethereum/contract/{address}/nfts # NFTs GET /events/collection/{address} # Eventos GET /orders/ethereum/seaport/listings # Listings GET /orders/ethereum/seaport/offers # Ofertas

  • JavaScript ES6+ con clases
  • OpenSea API v2

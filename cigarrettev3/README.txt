Cigarette Mini (Canvas + PNG embedded)

- Single-file HTML with no external assets.
- Designed for marketplaces that proxy `animation_url` (like OpenSea): all frames are embedded as data URIs.

How to use:
1) Upload index.html to IPFS (or any static host that serves text/html).
2) Set your NFT metadata `animation_url` to that URL.
3) Keep `image` as a static preview (PNG/SVG) for thumbnails.

Controls:
- Click/Tap "Puff" or press Space.
- Background selector included.

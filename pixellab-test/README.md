# PixelLab Test - Pruebas de Pixel Art AI

Esta carpeta contiene pruebas y ejemplos de uso de PixelLab AI para generar pixel art.

## Herramientas Disponibles

PixelLab MCP proporciona herramientas para:
- Generar sprites de pixel art
- Editar imágenes existentes
- Convertir imágenes a pixel art
- Crear assets para juegos

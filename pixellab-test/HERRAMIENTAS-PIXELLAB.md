# Herramientas PixelLab MCP

## Cómo Consultar las Herramientas Disponibles

Para ver qué herramientas tiene PixelLab MCP disponibles, puedes:

1. **En Cursor Chat**: Pregunta directamente:
   - "¿Qué herramientas de PixelLab MCP están disponibles?"
   - "Lista las herramientas de PixelLab"
   - "Muestra las funciones de PixelLab"

2. **Verificar en la configuración MCP**: 
   - Revisa el archivo de configuración MCP en Cursor
   - Las herramientas deberían aparecer en el panel de MCP

## Herramientas Típicas de PixelLab

Basado en servicios similares, PixelLab probablemente incluye:

- **generate_sprite**: Generar sprites de pixel art
- **edit_pixel_art**: Editar imágenes de pixel art existentes
- **convert_to_pixel_art**: Convertir imágenes normales a pixel art
- **create_animation**: Crear animaciones de sprites
- **upscale_pixel_art**: Escalar pixel art manteniendo calidad

## Uso de Ejemplo

Una vez que conozcas las herramientas exactas, puedes usarlas así:

```
Genera un sprite de 32x32 píxeles de un punk con cabello morado
```

O:

```
Crea un sprite de 64x64 de un personaje retro con sombrero
```

## Notas

- Los sprites generados se guardarán en esta carpeta
- Usa formato SVG o PNG según lo que genere PixelLab
- Asegúrate de especificar el tamaño exacto que necesitas

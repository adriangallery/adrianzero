# Traits Assets

Esta carpeta contiene las imágenes SVG de los traits para el TraitLAB Playground.

## Estructura de archivos

Sube las imágenes SVG con el siguiente formato de nombre:

```
{tokenId}.svg
```

Ejemplos:
- `1.svg` - Trait con tokenId 1
- `2.svg` - Trait con tokenId 2
- `475.svg` - Trait con tokenId 475
- `482.svg` - Trait con tokenId 482

## Cómo subir

1. Sube todos los archivos SVG a esta carpeta
2. Asegúrate de que el nombre del archivo coincida con el tokenId
3. El playground cargará automáticamente las imágenes disponibles

## Formato de imagen

- **Formato**: SVG
- **Tamaño**: Recomendado 200x200px o similar
- **Fondo**: Transparente preferiblemente
- **Calidad**: Alta resolución para mejor visualización

## Notas

- El playground detectará automáticamente qué imágenes están disponibles
- Si una imagen no existe, se mostrará un placeholder
- Las imágenes se cargan localmente para mejor performance
